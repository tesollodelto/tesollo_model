## 👋 DG5F

### 📁 Directory Structure & Supported Formats

#### 1. Meshes (`.stl`, `.dae`)
3D mesh files for visual rendering and collision detection.
* `meshes/dg5f_left/*.stl, *.dae`
* `meshes/dg5f_right/*.stl, *.dae`
* `meshes/dg5f_left_short/*.stl, *.dae`
* `meshes/dg5f_right_short/*.stl, *.dae`
* `meshes/dg5f_left_force_v1/*.stl, *.dae`
* `meshes/dg5f_right_force_v1/*.stl, *.dae`
* `meshes/dg5f_left_ft_v1/*.stl, *.dae`
* `meshes/dg5f_right_ft_v1/*.stl, *.dae`


#### 2. URDF (`.urdf`)
Standard robot model files for ROS and general-purpose robotics simulators.
* `dg5f_left.urdf`
* `dg5f_right.urdf`
* `dg5f_left_short.urdf`
* `dg5f_right_short.urdf`
* `dg5f_force_v1_left.urdf`
* `dg5f_force_v1_right.urdf`
* `dg5f_ft_v1_left.urdf`
* `dg5f_ft_v1_right.urdf`

#### 3. MJCF (`.xml`)
Model files optimized for the MuJoCo physics engine.
* `dg5f_left.xml`
* `dg5f_right.xml`
* `dg5f_left_short.xml`
* `dg5f_right_short.xml`

#### 4. USD (`.usd`)
Ready-to-use USD files specifically configured for NVIDIA Isaac Sim and Isaac Lab environments.
* `usd/dg5f_left/dg5f_left.usd`
* `usd/dg5f_right/dg5f_right.usd`
* `usd/dg5f_left_short/dg5f_left_short.usd`
* `usd/dg5f_right_short/dg5f_right_short.usd`
* `usd/dg5f_force_v1_left/dg5f_force_v1_left.usd`
* `usd/dg5f_force_v1_right/dg5f_force_v1_right.usd`
* `usd/dg5f_ft_v1_left/dg5f_ft_v1_left.usd`
* `usd/dg5f_ft_v1_right/dg5f_ft_v1_right.usd`
* `usd/dg5f_right_tactile/dg5f_right_tactile.usd`
